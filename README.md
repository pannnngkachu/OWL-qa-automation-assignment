# Sauce Demo Automation Assignment

## Project Structure
- pages/
- tests/

## Tool Used
- Playwright
- JavaScript
- Node.js

## How to Run

1. Install dependencies

npm install

2. Run test

npx playwright test

## Covered Scenario

- Login with valid user
- Add 2 products
- Verify cart
- Checkout process
- Verify pricing visible
- Complete order
- Logout successfully

## Assumptions

- Standard user account is active
- Stable internet connection
- SauceDemo selectors remain unchanged
